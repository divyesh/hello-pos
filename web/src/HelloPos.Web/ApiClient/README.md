# Generated API client

Everything in this folder except this file is generated by
[Kiota](https://learn.microsoft.com/openapi/kiota/) from `contracts/openapi.yaml`. Do not edit it by
hand: change the contract, then regenerate from the repository root:

```text
scripts/dotnet.ps1 tool restore
scripts/dotnet.ps1 kiota generate --language CSharp --class-name HelloPosApiClient --namespace-name HelloPos.Web.ApiClient --openapi contracts/openapi.yaml --output web/src/HelloPos.Web/ApiClient --exclude-backward-compatible
```

(`scripts/dotnet.sh` on Linux/macOS.) Commit the regenerated files with the contract change. The
Kiota version is pinned in `.config/dotnet-tools.json`; `kiota-lock.json` records the settings used.
